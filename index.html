🎯 Наша задача: построить настоящий уровень Obby

Представь, что игрок идёт по мосту. Впереди зелёная площадка — чекпоинт. После неё находится красная лава. Если игрок наступил на лаву, он погибает, но появляется на последнем чекпоинте, а не в начале.

🏁 Старт　→　🟩 Чекпоинт　→　🔥 Лава　→　♻️ Возрождение на 🟩

Сегодня не нужно запоминать длинный код целиком. Сначала научимся создавать детали в Studio, затем узнаем, как программа распознаёт персонажа, и только потом соберём механику.

Все действия ниже рассчитаны на Roblox Studio на компьютере. Названия кнопок даны по английскому интерфейсу.

Урок · Шаг 1

🧱 Готовим игровую площадку

Сначала создадим мир. Part — обычный строительный блок. Workspace — место, где находятся объекты нашего уровня. Explorer — список объектов, а Properties — их настройки.

🖱️ Куда нажимать в Roblox Studio

  1. Открой Roblox Studio и выбери шаблон Baseplate.
  2. В верхнем меню открой вкладку View (или Window, если в твоей версии панели находятся там) и включи Explorer, Properties и Output.
  3. В верхней панели открой Home → Part. На карте появится блок.
  4. Найди новый Part в Explorer → Workspace и щёлкни по нему.
  5. В Properties найди Name и назови его Lava. Установи Anchored = true, чтобы блок не падал.
  6. Через Properties → Color выбери красный цвет, а через Size увеличь блок, например до 12, 1, 12.
▶ Как проверить: Нажми Home → Play. Попробуй пройти по карте и найти красный блок. Затем нажми Stop. Пока лава безопасна — мы ещё не добавили скрипт.
Урок · Шаг 2

👣 Учим лаву замечать касание

Touched — событие: Roblox сообщает скрипту, что с блоком что-то соприкоснулось. hit — имя переменной, в которую Roblox положит ту деталь, которая коснулась лавы. Это может быть нога игрока, мяч или другой кубик.

🖱️ Куда нажимать в Roblox Studio

  1. В Explorer найди Workspace → Lava.
  2. Наведи курсор на Lava и нажми значок + рядом с названием.
  3. В поиске введи Script и выбери обычный Script (не LocalScript).
  4. Дважды щёлкни по новому Script и удали текст, который Roblox вставил автоматически.
  5. Впиши код ниже.

💻 Код, который мы пишем

local lava = script.Parent

lava.Touched:Connect(function(hit)
    print("К лаве прикоснулся:", hit.Name)
end)

🔍 Разбираем каждую строку

local lava = script.Parent — берём объект, внутри которого лежит наш Script: это лава.

lava.Touched — обращаемся к событию касания лавы.

:Connect(function(hit) — говорим: «когда кто-то коснётся, выполни команды ниже». Roblox сам передаст нам hit.

print(..., hit.Name) — показываем в Output название коснувшейся детали.

end) — заканчиваем функцию.

▶ Как проверить: Открой View → Output, нажми Play и наступи на красный блок. В Output появятся названия частей персонажа, например LeftFoot. После проверки нажми Stop.
Урок · Шаг 3

❤️ Узнаём, игрок это или обычный кубик

Humanoid — специальный объект внутри модели персонажа Roblox. Он хранит здоровье (Health) и помогает персонажу двигаться. У обычного кубика Humanoid нет, поэтому его нужно сначала найти и проверить.

🖱️ Куда нажимать в Roblox Studio

  1. В Explorer → Workspace → Lava → Script открой наш скрипт.
  2. Замени предыдущий код на код ниже.
  3. Обрати внимание: мы добавили поиск Humanoid и условие if.

💻 Код, который мы пишем

local lava = script.Parent

lava.Touched:Connect(function(hit)
    local character = hit.Parent
    local humanoid = character:FindFirstChildOfClass("Humanoid")

    if humanoid then
        print("Это персонаж!")
    end
end)

🔍 Разбираем каждую строку

hit.Parent — находим модель, которой принадлежит коснувшаяся деталь.

local humanoid = ... — пытаемся найти внутри модели объект класса Humanoid.

if humanoid then — если Humanoid найден, значит можно работать с персонажем.

print(...) — выводим сообщение только для персонажа.

▶ Как проверить: Нажми Play, коснись лавы персонажем — в Output появится «Это персонаж!». Для сравнения можно бросить на лаву обычный Part: сообщение для него не появится.
Урок · Шаг 4

🔥 Превращаем красный блок в настоящую лаву

Теперь добавим одну важную строку: humanoid.Health = 0. Это означает «установить здоровье персонажа равным нулю». После этого Roblox запустит стандартную механику гибели.

🖱️ Куда нажимать в Roblox Studio

  1. В Explorer → Workspace → Lava → Script открой код.
  2. Замени содержимое на готовый пример ниже.
  3. Убедись, что строка humanoid.Health = 0 стоит внутри проверки if humanoid then.

💻 Код, который мы пишем

local lava = script.Parent

lava.Touched:Connect(function(hit)
    local character = hit.Parent
    local humanoid = character:FindFirstChildOfClass("Humanoid")

    if humanoid then
        humanoid.Health = 0
    end
end)

🔍 Разбираем каждую строку

local lava = script.Parent — получаем наш красный блок.

Touched:Connect(...) — ждём касания.

hit.Parent — получаем модель того, кто коснулся лавы.

FindFirstChildOfClass("Humanoid") — проверяем, есть ли у модели здоровье персонажа.

if humanoid then — защищаем код от ошибок, если коснулся не игрок.

humanoid.Health = 0 — обнуляем здоровье персонажа.

▶ Как проверить: Нажми Home → Play, подойди к лаве и наступи на неё. Персонаж должен погибнуть и через некоторое время появиться снова. Если ничего не произошло, открой Output и проверь ошибки.
Урок · Шаг 5

🟩 Что такое чекпоинт и почему он не обычный Part?

Чекпоинт — место, на котором игрок сможет появиться после гибели. Для этого в Roblox существует специальный объект SpawnLocation. Обычный Part выглядит как платформа, но не умеет самостоятельно быть точкой возрождения.

🖱️ Куда нажимать в Roblox Studio

  1. Останови игру кнопкой Stop.
  2. В Explorer щёлкни правой кнопкой по Workspace и выбери Insert Object (или нажми + справа от Workspace).
  3. В поиске набери SpawnLocation и добавь его.
  4. Переименуй объект в Checkpoint1.
  5. В Properties установи Anchored = true и Neutral = true. Выбери зелёный Color.
  6. С помощью инструмента Move перемести чекпоинт перед лавой так, чтобы на него можно было наступить.
▶ Как проверить: Нажми Play и убедись, что зелёная площадка находится на уровне пола и персонаж может на неё встать. Пока точка ещё не сохраняется — добавим код на следующем шаге.
Урок · Шаг 6

📍 Как запомнить чекпоинт конкретного игрока

Игрок и персонаж — не одно и то же. Player — участник игры; Character — его модель на карте. GetPlayerFromCharacter помогает найти участника по его персонажу. А RespawnLocation указывает, на какой SpawnLocation игрок появится в следующий раз.

🖱️ Куда нажимать в Roblox Studio

  1. Останови игру кнопкой Stop.
  2. В Explorer → Workspace → Checkpoint1 нажми + и добавь обычный Script.
  3. Дважды щёлкни по скрипту и замени стандартный текст кодом ниже.
  4. Проверь, что Script находится внутри Checkpoint1, а не внутри Lava.

💻 Код, который мы пишем

local checkpoint = script.Parent
local Players = game:GetService("Players")

checkpoint.Touched:Connect(function(hit)
    local character = hit.Parent
    local player = Players:GetPlayerFromCharacter(character)

    if player then
        player.RespawnLocation = checkpoint
        print("Чекпоинт сохранён!")
    end
end)

🔍 Разбираем каждую строку

checkpoint = script.Parent — получаем зелёную площадку.

game:GetService("Players") — получаем сервис, который знает всех игроков.

checkpoint.Touched — ждём, когда кто-то коснётся чекпоинта.

hit.Parent — узнаём модель коснувшегося объекта.

GetPlayerFromCharacter(character) — пытаемся найти игрока, который управляет этой моделью.

if player then — продолжаем только если нашли настоящего игрока.

player.RespawnLocation = checkpoint — назначаем чекпоинт новой точкой появления этого игрока.

print(...) — показываем сообщение в Output.

▶ Как проверить: Нажми Play → наступи на зелёный чекпоинт → посмотри Output → наступи на лаву. После гибели персонаж должен появиться на зелёной площадке. Если нет, проверь, что чекпоинт именно SpawnLocation, его Neutral = true и скрипт вложен внутрь него.
Урок · Шаг 7

🔒 Зачем нужен переключатель busy?

Один игрок может касаться кнопки сразу несколькими частями тела, и Touched сработает несколько раз. busy — это переключатель: false значит «свободно», true — «занято». return означает «выйди из функции прямо сейчас».

🖱️ Куда нажимать в Roblox Studio

  1. Останови игру кнопкой Stop.
  2. Добавь новый обычный Part через Home → Part, назови его Button, поставь Anchored = true и покрась в жёлтый.
  3. В Explorer → Workspace → Button добавь обычный Script.
  4. Вставь код ниже.

💻 Код, который мы пишем

local button = script.Parent
local busy = false

button.Touched:Connect(function(hit)
    local humanoid = hit.Parent:FindFirstChildOfClass("Humanoid")
    if not humanoid then
        return
    end

    if busy then
        return
    end

    busy = true
    print("Кнопка нажата!")
    task.wait(2)
    busy = false
end)

🔍 Разбираем каждую строку

busy = false — кнопка пока свободна.

if not humanoid then return end — если это не персонаж, ничего не делаем.

if busy then return end — если кнопка уже занята, повторное касание игнорируем.

busy = true — блокируем повторные нажатия.

task.wait(2) — ждём примерно две секунды.

busy = false — снова разрешаем нажатия.

▶ Как проверить: Нажми Play и несколько раз наступи на жёлтую кнопку. Сообщение в Output должно появляться не чаще одного раза за две секунды.

  4. Что меняет Health = 0?
  5. Почему чекпоинт хранится в player.RespawnLocation?

Этап 1 · Мир

Создай стартовую платформу, мостик и лаву. Настрой цвет, размер, положение и Anchored.

Этап 2 · Опасность

Этап 3 · Сохранение

Добавь SpawnLocation и Script, который обновляет RespawnLocation.

Этап 4 · Проверка

Нажми Play, активируй чекпоинт, погибни в лаве и проверь место возрождения.
